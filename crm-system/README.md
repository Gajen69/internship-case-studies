# 2. CRM System with Dashboard
Problem: The team tracked projects over WhatsApp. No database, no dashboard, no way to separate departments, and things got confusing.<br>
Solution: A CRM built on Google Sheets + Apps Script with:<br>
Role-based access (only team leaders can change project status)<br>
Auto email to the team leader when a task isn't completed<br>
Service selection that auto-fills the amount and timeline<br>
Document upload via Drive, and sharing with clients directly<br>
A dashboard with totals per service, team leader tasks, and month-over-month % comparison<br>
Users: 8 to 10 staff at a startup company<br>
Result: One source of truth instead of scattered chats, with automatic follow-ups.<br>
What I'd improve: Move to a real database if the team grows.
